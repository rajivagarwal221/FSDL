# Full Stack Development Lab (FSDL)

Weekly lab work for the Full Stack Development Lab course (roll no. 5024101), from plain HTML through Bootstrap, JavaScript, Java and React. Each folder is one week's practical.

| Week | Folder | Topics |
| --- | --- | --- |
| 1 | [`WEEK1_19_1_26`](WEEK1_19_1_26) | HTML basics: structure, text, lists, tables, links |
| 2 | [`Week2_2-2-26`](Week2_2-2-26) | CSS styling, ID card layout |
| 3 | [`WEEK3_9_2-26(bootstrap)`](<WEEK3_9_2-26(bootstrap)>) | Bootstrap: grid and spacing, buttons, forms, navbar and breadcrumbs, jumbotron and colours |
| 4 | [`WEEK4_16_2_26`](WEEK4_16_2_26) | JavaScript: variables and operators, conditions, loops, functions, classes and objects |
| 5 | [`WEEK5_23_2_26`](WEEK5_23_2_26) | Java: arrays, strings, date and time, error handling, validations |
| 7 | [`WEEK_7`](WEEK_7) | AngularJS hello world |
| — | [`my-react-app`](my-react-app) | React + Vite app with routing, dark mode, hooks and components |

## Running the examples

- **HTML / CSS / Bootstrap:** open the `.html` file in a browser.
- **JavaScript:** `node WEEK4_16_2_26/loops.js`
- **Java:** `cd WEEK5_23_2_26 && javac ArraysDemo.java && java ArraysDemo`
- **React app:**

  ```bash
  cd my-react-app
  npm install
  npm run dev    # http://localhost:5173
  ```

## Tech used

HTML5, CSS3, Bootstrap 5, JavaScript (ES6+), Java, AngularJS, React, Vite, React Router.
